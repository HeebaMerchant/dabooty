# Da Booty Club Friendsgiving

A shared table for Da Booty Club. Claim a dish, keep the classics from doubling up, pin photos to memory lane, and drop a PowerPoint for everyone else.

## Run it

```bash
npm start
```

Node 18 or newer is enough. There is nothing else to install.

Open the local URL the server prints. Friends on the same Wi-Fi can use the network URL.

Dishes, RSVPs, photos, and decks are stored in `data/` on the machine running the server.

## What it catches

Mac & cheese and macaroni and cheese count as one dish. So do typos (`pumkin pie`) and “my famous” versions of a classic. Apple pie and pumpkin pie can both show up. Turkey and turkey gravy can both show up. A name as broad as “pie” gets sent back for a fuller title.
